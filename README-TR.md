## 📋 Hakkında

Bu web sitesi, **Flutter mobil geliştirme** ve ölçeklenebilir bulut/backend mimarileri konularında uzmanlaşmış Kıdemli Yazılım Mühendisi **Mohd Mustak**'ın etkileşimli portföyüdür. Awwwards kalitesinde yatay kaydırma, fizik tabanlı mikro etkileşimler, etkileşimli arka plan parçacıkları, çift dil seçeneği (İngilizce ve Türkçe) ve derin uygulama mağazası indirme butonları içerir.

## <a id="features"></a> ✨ Özellikler

- **Gelişmiş Animasyonlar**: Framer Motion ile akıcı yatay geçişler, özel zaman çizelgesi yerleşimleri ve yaylı fizik geçişleri.
- **Fizik Tabanlı Tuval**: Fare hareketlerine fiziksel tepki veren sarkaçlı profil penceresi ("Hanging Profile").
- **Dinamik Proje Akışı**: 6 adet gerçek dünyada yayınlanmış mobil ve web uygulamasını gösteren yatay proje şeridi.
- **Uygulama Vitrini**: Ayrıştırılmış görsel yapısı sayesinde kartlarda tam ekran ekran görüntüleri gösterilirken, detay penceresinde 1:1 uygulama logoları ve yatay kaydırılabilir dikey ekran görüntüleri gösterilir.
- **Çoklu Dil Desteği**: İngilizce ve Türkçe arasında anında geçiş sağlayan yerelleştirme sistemi.
- **Duyarlı Tasarım**: Mobil ve masaüstü ekran boyutları için otomatik olarak biçimlendirilen esnek tasarım.

## <a id="projects"></a> 📱 Sergilenen Uygulamalar

1. **Marhaba Auctions**: Canlı teklif verme (WebSockets), ödeme entegrasyonu ve araç takip sistemlerini barındıran ihale uygulaması.
2. **Koor Property**: Körfez ülkeleri için sıfır reklam bütçesiyle 10 binden fazla indirmeye ulaşan emlak platformu.
3. **Movermate Crew**: Geofencing, takvim planlama ve Stripe Tap-to-Pay entegrasyonlu taşımacılık uygulaması.
4. **Counsellor App**: Arama günlükleri, dahili arama ve arama kaydı gibi CRM özelliklerini barındıran B2B iş uygulaması.
5. **Spotted**: QR kod ödeme, anında nakit iade ve cüzdan entegrasyonlu fintech platformu.
6. **SSC Exam Prep AI**: Gemini API ve yerel LLM (Phi-4) modelleri ile PDF'lerden otomatik soru üreten yapay zekâ destekli quiz uygulaması.

## <a id="tech"></a> 🛠️ Teknolojiler

- **Next.js & TypeScript**: Yüksek performans ve tip güvenliği sağlayan temel framework.
- **Tailwind CSS**: Modern arayüz tasarımı ve tema değişkenleri.
- **Framer Motion**: Etkileşimli hareketler, geçişler ve yaylı animasyonlar.
- **Three.js & React Three Fiber**: İnteraktif ve hafif 3D arka plan parçacık sahneleri.
- **Lenis**: Tüm cihazlarda akıcı kaydırma deneyimi sunan yumuşak kaydırma kütüphanesi.

## <a id="installation"></a> 🚀 Kurulum

Projeyi yerel ortamda çalıştırmak için:

1. **Bağımlılıkları yükleyin:**
   ```bash
   npm install
   ```

2. **Geliştirme sunucusunu başlatın:**
   ```bash
   npm run dev
   ```

3. **Üretim sürümünü derleyin:**
   ```bash
   npm run build
   ```
